# kiva-loans-analysis

Six questions exploring funding, loan requests and repayment patterns in the Kiva loans dataset.

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Jeremiahameh/kiva-loans-analysis/blob/main/Kiva_Loans_Jeremiah_Ameh.ipynb)

## Dataset and running the notebook

Download `kiva_loans.csv` from:
https://www.kaggle.com/datasets/kiva/data-science-for-good-kiva-crowdfunding

Upload it to the main folder of your Google Drive (My Drive).

Open the notebook using the Colab button above, run the cells, and connect your Google Drive when prompted. The notebook reads the file from `/content/drive/MyDrive/kiva_loans.csv`.
